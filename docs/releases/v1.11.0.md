# ADR Guard CLI v1.11.0

[Português (Brasil)](v1.11.0.pt-BR.md)

ADR Guard CLI `1.11.0` was published on 2026-11-05 to NuGet.org, GitHub Packages, GitHub Releases, GHCR, and Docker Hub. The exact `v1.11.0` tag and moving `v1` Action tag point to the release commit.

## Highlights

- Adds native MADR 4.0 generation to `adr-guard new` with built-in `minimal` and `extended` templates.
- Selects MADR explicitly with `--adr-format madr-4` or repository configuration while canonical generation remains the default.
- Supports exact, side-effect-free `--preview` and `--dry-run` output and schema `1.0` `new --form` operations.
- Preserves atomic writes, filename policies, bounded inputs, and human-owned approval of generated `proposed` drafts.

## Compatibility

- Existing canonical templates and generated bytes remain unchanged; custom templates remain canonical-only.
- The `new --form` envelope remains schema `1.0` and reuses existing field IDs.
- Existing arguments, exit codes `0`–`4`, validation schemas, deterministic ordering, and approval boundaries remain compatible.
- The runtime remains .NET 10 and native MADR generation requires neither MCP nor an AI provider.

## Distribution

The coordinated manual Release workflow completed package, container, exact/moving Action tag, and GitHub Release publication for `1.11.0`.

## Independent components

- `AdrGuard.Core` remains internal and non-packable.
- MCP `1.0.1` is independently published on NuGet.org, GitHub Releases, and the MCP Registry.
- VS Code `1.1.1` is independently published in the Visual Studio Marketplace and invokes a separately installed compatible CLI.
- The Phase 3 `relationships` command is not part of this immutable release; it is prepared for CLI `1.12.0`.
