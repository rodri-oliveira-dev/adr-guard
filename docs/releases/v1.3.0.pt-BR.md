# ADR Guard v1.3.0

## Destaques

- **MADR 4.0:** Validação opt-in de documentos MADR 4.0 baseada nos templates oficiais completo e mínimo. Selecione esse formato usando `--adr-format madr-4` ou a configuração correspondente.
- **Governança de relacionamentos:** Diagnósticos determinísticos `ADR010`–`ADR014` para dependências, substituições e referências explícitas entre decisões arquiteturais, complementando `ADR001`–`ADR009`.
- **Relatórios consistentes:** Ampliação das saídas texto, JSON e SARIF para os novos códigos, preservando os contratos de integração existentes.

## Compatibilidade

- O **formato canônico continua sendo o padrão**. Repositórios com ADRs existentes não precisam migrar para MADR.
- Consumidores da CLI, .NET Tool e GitHub Action continuam utilizando exit codes explícitos e códigos estáveis de diagnóstico.
- Validação incremental com Git, baselines de diagnósticos e revisão comparativa por IA entre duas versões **não fazem parte da v1.3.0**; esses recursos ficam para a futura v1.4.0.

## Distribuição

A .NET Tool `RodriOliveira.AdrGuard`, a GitHub Action e as imagens de container são publicadas pelo workflow manual de release coordenada, com versão exata `1.3.0` e tag Git `v1.3.0`. O merge deste PR não dispara a publicação.

Instalação via NuGet.org **após a publicação**:

```bash
dotnet tool install --global RodriOliveira.AdrGuard --version 1.3.0
```
