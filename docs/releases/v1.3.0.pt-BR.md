# Notas de preparação da v1.3.0

Este é um documento de preparação do código, não um anúncio de release.

- Adiciona validação MADR 4.0 explícita baseada nos templates oficiais 4.0.0 full/minimal.
- Mantém o formato canônico do ADR Guard como default e exige `--adr-format madr-4` ou configuração.
- Adiciona diagnósticos determinísticos ADR010-ADR014 para o grafo explícito, preservando ADR001-ADR009.
- Estende texto, JSON, SARIF e o relatório futuro da Action para os novos códigos estáveis.

Repositórios existentes não precisam migrar ADRs. A branch v1.3 define `VersionPrefix` como `1.3.0`; a CI e os testes de política de release derivam as versões desse valor. O PR aponta para `main` e precisa passar na CI antes do merge. A publicação de `v1.3.0` exige uma execução manual e independente após a integração.
