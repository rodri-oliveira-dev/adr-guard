# ADR Guard v1.3.0

Publicada em **08/10/2026**, a v1.3.0 do ADR Guard consolida **em uma única release estável** as funcionalidades originalmente preparadas nas branches de desenvolvimento v1.3 e v1.4. Consulte a [release publicada no GitHub](https://github.com/rodri-oliveira-dev/adr-guard/releases/tag/v1.3.0).

## Formatos de validação e governança arquitetural

- Adiciona validação MADR 4.0 explícita e opcional, baseada nos templates oficiais completo e mínimo. Selecione com `--adr-format madr-4` ou pela configuração correspondente; o formato canônico continua sendo o padrão.
- Adiciona governança determinística de relacionamentos entre ADRs com diagnósticos `ADR010`–`ADR014`, preservando `ADR001`–`ADR009`.
- Estende os relatórios de texto, JSON (schema 1.0), SARIF e integrações para os códigos aplicáveis.

## Validação incremental com Git e baselines

- Disponibiliza **validação incremental opcional** de ADRs alteradas com `check --changed --base-ref <ref>`, preservando verificações globais de integridade e sem executar fetch implícito.
- Adiciona baselines de diagnósticos estritos e versionados, com comandos explícitos de criação/atualização atômica.
- Relata diagnósticos novos, existentes e resolvidos de forma consistente. Calcula as resoluções sobre o conjunto completo de ADRs antes de filtrar novos/existentes no modo incremental.
- Valida referências-base do Git e remove fingerprints duplicados antes de gravar baselines.

## Revisão arquitetural comparativa

- Adiciona revisão assistida por IA entre duas versões do mesmo ADR, acionada explicitamente, com contexto histórico limitado e preservando os controles de provider, segurança e revisão humana.
- Inclui testes determinísticos com Git real, provider simulado, cancelamento, segurança e regressão, além de documentação bilíngue.

## Compatibilidade e publicação

- Repositórios que usam ADRs canônicas **não precisam migrar**. MADR, validação incremental, baselines e revisão comparativa são recursos opcionais ou explícitos.
- As funcionalidades antes planejadas para a `v1.4.0` **fazem parte da v1.3.0**. Não estão adiadas para outra release de funcionalidades.
- O PackageId continua sendo `RodriOliveira.AdrGuard` e o comando da .NET Tool continua sendo `adr-guard`.
- A versão 1.3.0 foi publicada pelo workflow `Release`, acionado manualmente e protegido por validações de CI, no NuGet.org, GitHub Packages, registries de containers, tags da GitHub Action e GitHub Releases. As próximas releases continuam exigindo autorização manual explícita e CI bem-sucedida.

Instale esta versão publicada com:

```bash
dotnet tool install --global RodriOliveira.AdrGuard --version 1.3.0
```
