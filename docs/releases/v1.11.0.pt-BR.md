# ADR Guard CLI v1.11.0

[English](v1.11.0.md)

A CLI ADR Guard `1.11.0` foi publicada em 05/11/2026 no NuGet.org, GitHub Packages, GitHub Releases, GHCR e Docker Hub. A tag exata `v1.11.0` e a tag móvel `v1` da Action apontam para o commit da release.

<!-- release-candidate-only:start -->
<!-- release-candidate-only:end -->

## Principais mudanças

- Adiciona geração MADR 4.0 nativa ao `adr-guard new` com templates internos `minimal` e `extended`.
- Seleciona MADR explicitamente com `--adr-format madr-4` ou pela configuração do repositório, mantendo a geração canônica como padrão.
- Suporta saída exata e sem efeitos colaterais por `--preview` e `--dry-run`, além das operações `new --form` no schema `1.0`.
- Preserva escrita atômica, políticas de nomes, entradas limitadas e aprovação humana dos rascunhos `proposed` gerados.

## Compatibilidade

- Templates canônicos existentes e seus bytes gerados permanecem inalterados; templates personalizados continuam exclusivamente canônicos.
- O envelope `new --form` permanece no schema `1.0` e reutiliza os IDs de campos existentes.
- Argumentos, códigos de saída `0`–`4`, schemas de validação, ordenação determinística e limites de aprovação permanecem compatíveis.
- O runtime continua sendo .NET 10 e a geração MADR nativa não exige MCP nem provider de IA.

## Distribuição

O workflow manual coordenado Release concluiu a publicação do pacote, containers, tags exata/móvel da Action e GitHub Release da `1.11.0`.

## Componentes independentes

- `AdrGuard.Core` permanece interno e sem pacote.
- MCP `1.0.1` está publicado independentemente no NuGet.org, GitHub Releases e MCP Registry.
- VS Code `1.1.1` está publicado independentemente no Visual Studio Marketplace e executa uma CLI compatível instalada separadamente.
- O comando `relationships` da Fase 3 não integra esta release imutável; ele está preparado para a CLI `1.12.0`.
