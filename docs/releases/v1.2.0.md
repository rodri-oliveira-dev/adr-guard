# v1.2.0 preparation notes

This document describes the source state prepared for review. It is not a release announcement.

- Adds safe, idempotent `adr-guard init` with dry-run and optional least-privilege workflow generation.
- Adds strict optional `.adrguard.yml` configuration with CLI-first precedence and legacy-compatible absence behavior.
- Adds deterministic JSON schema v1 and SARIF 2.1.0 output to `check` without changing text defaults or exit codes.
- Keeps deterministic commands offline and preserves the manual release/distribution strategy.

Migration is optional: existing invocations continue to work without a configuration file. Before publishing v1.2.0, merge the reviewed PR, run the existing manual release workflow independently, and verify NuGet, GHCR, Docker Hub, and Action artifacts.
