# Historical v1.4.0 planning notes (superseded)

**These notes describe the original development branch, not a separate release scheduled for publication.** The previously planned v1.4 feature set was published in the consolidated **v1.3.0** package. See [v1.3.0 release notes](v1.3.0.md).

The original v1.4 development scope included:

- Safe, opt-in Git incremental validation with mandatory global integrity checks.
- Strict versioned diagnostic baselines with explicit atomic creation/update and new/existing/resolved reporting.
- Full-set baseline resolution accounting before filtering changed-file diagnostics.
- Validated Git base references and deduplicated baseline fingerprints.
- Explicit same-file comparative AI review using bounded two-version context.
- Deterministic real-Git, mock-provider, security, cancellation, and regression tests.
- Bilingual documentation for shallow history, baselines, migrations, comparative review, and fork-safe CI.

All of the above shipped in **v1.3.0**, together with MADR 4.0 and relationship governance. Future releases remain manually dispatched and subject to CI and immutable version-tag safeguards.
