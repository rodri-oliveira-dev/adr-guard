# ADR Guard CLI v1.9.0

[English](v1.9.0.md)

A CLI ADR Guard `1.9.0` está publicada no [NuGet.org](https://www.nuget.org/packages/RodriOliveira.AdrGuard/1.9.0) e na [GitHub Release exata `v1.9.0`](https://github.com/rodri-oliveira-dev/adr-guard/releases/tag/v1.9.0). Os dois canais e a tag móvel de compatibilidade `v1` da Action foram verificados novamente em 03/11/2026; a tag aponta para o mesmo commit da release.

## Principais mudanças

- Adiciona `check --diagnostic-locations` para que relatórios JSON e SARIF possam incluir linha e coluna baseadas em evidência e numeradas a partir de um. Sem a flag, o formato existente do relatório não muda.
- Preserva localizações conhecidas pelo parser em achados de relacionamento, inclusive quando a seção `Superseded by` existe, mas está vazia ou inutilizável.
- Usa o assembly interno `AdrGuard.Core` para parsing, validação, configuração, inventário Git, impacto e drift compartilhados. O Core acompanha o pacote da CLI e não é uma biblioteca NuGet pública nem uma release independente.
- Melhora a resolução do diretório Git físico em aliases de caminho do macOS e amplia a cobertura de confiabilidade multiplataforma da CLI.

## Correções e melhorias internas

- Mantém no nível de arquivo os achados sem evidência confiável de origem, sem inventar coordenadas.
- Adiciona smoke tests determinísticos da CLI para `init`, `new`, `check`, `index`, validação incremental, schema JSON `1.0` e saídas `0`/`1` no CI Linux, Windows e macOS.
- Adiciona um baseline de performance informativo e reproduzível. Ele não é SLA nem gate de release.
- Empacota `AdrGuard.Core.dll` com a CLI e exclui o executável MCP.

## Compatibilidade e requisitos

- Exige .NET 10.
- Preserva todos os comandos, argumentos, defaults, exit codes (`0`–`4`), schema JSON `1.0`, SARIF `2.1.0`, identidades/fingerprints de diagnóstico, contratos de formulário e ordenação determinística existentes.
- A extensão VS Code `1.1.0` publicada pode usar esta CLI quando instalada separadamente. Sua integração com Problems solicita localizações precisas e mantém o fallback para versões anteriores da CLI.
- O MCP é versionado e instalado de forma independente. MCP `1.0.0` é a versão publicada; `1.0.1` continua sendo candidata no código-fonte. Nenhum executável depende do outro.

## Mudanças de comportamento

O único comportamento público novo da CLI é opcional. Com `--diagnostic-locations` e saída JSON ou SARIF, os achados incluem linha/coluna somente quando o parser reteve evidência concreta. A ausência da flag preserva o formato anterior da saída estruturada. Nenhuma regra, severidade, default, comando ou significado de exit code muda.

## Limitações conhecidas

- Alguns achados globais do repositório, de front matter ou de seção ausente não possuem coordenadas comprováveis e permanecem no nível de arquivo.
- As medições de performance dependem do ambiente e são apenas informativas.
- Draft e review por IA continuam opcionais, limitados e consultivos. Nem IA nem MCP podem aprovar uma ADR ou estabelecer conformidade.

## Instalar ou atualizar

Instale o pacote publicado com:

```shell
dotnet tool install --global RodriOliveira.AdrGuard --version 1.9.0
adr-guard --version
```
