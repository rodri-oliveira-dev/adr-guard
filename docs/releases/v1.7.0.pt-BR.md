# ADR Guard v1.7.0

O ADR Guard 1.7.0 adiciona contratos versionados de formulário para adaptadores confiáveis de criação e edição visual de ADRs. Estas notas descrevem o conteúdo da v1.7.0; a disponibilidade pública dos artefatos precisa ser confirmada separadamente no NuGet.org e nas Releases do GitHub.

## Destaques

- `adr-guard new <diretório> --form` oferece descoberta de templates nativos, prévias sem efeitos colaterais e criação atômica por mensagens stdin/stdout no schema `1.0`.
- `adr-guard edit <arquivo> --form` oferece carregamento sensível ao formato e atualização atômica no mesmo arquivo, com detecção de alterações externas.
- A edição preserva nomes de arquivo, identificadores de ADR, seções Markdown desconhecidas e conteúdos fora dos campos alterados pelo usuário.
- O comportamento existente de criação e validação pela linha de comando permanece retrocompatível.

## Instalar a v1.7.0

Após a publicação da release coordenada:

```shell
dotnet tool install --global RodriOliveira.AdrGuard --version 1.7.0
```

Para uma instalação existente:

```shell
dotnet tool update --global RodriOliveira.AdrGuard --version 1.7.0
```

A extensão VS Code continua sendo um adaptador sobre esses contratos. A validação e as regras de domínio de ADRs continuam sob responsabilidade da CLI.
