# ADR Guard v1.3.0

## Highlights

- **MADR 4.0:** Opt-in validation of MADR 4.0 documents based on the official full and minimal templates. Use `--adr-format madr-4` or the matching configuration to select this format.
- **Relationship governance:** Deterministic diagnostics `ADR010`–`ADR014` for explicit architectural decision dependencies, supersession and references, complementing `ADR001`–`ADR009`.
- **Consistent reports:** Extended text, JSON and SARIF validation outputs to include the new diagnostic codes, retaining the established machine-readable contracts.

## Compatibility

- The **canonical ADR Guard format remains the default**. Existing ADR repositories are not required to migrate to MADR.
- CLI, .NET Tool and GitHub Action consumers should continue to use explicit validation exit codes and stable diagnostic identifiers.
- Git incremental validation, diagnostic baselines and comparative two-version AI review are **not part of v1.3.0**; those capabilities are deferred to the subsequent v1.4.0 release.

## Distribution

The `RodriOliveira.AdrGuard` .NET Tool, the GitHub Action, and container images are released through the existing manual, coordinated release workflow using exact version `1.3.0` and Git tag `v1.3.0`. The release workflow is not triggered by merging this PR.

Install this version from NuGet.org **after publication**:

```bash
dotnet tool install --global RodriOliveira.AdrGuard --version 1.3.0
```
