# v1.3.0 preparation notes

This is a source-preparation document, not a release announcement.

- Adds explicit MADR 4.0 validation based on the official 4.0.0 full/minimal templates.
- Keeps the canonical ADR Guard format as the default and requires `--adr-format madr-4` or configuration.
- Adds deterministic explicit relationship graph diagnostics ADR010-ADR014 while preserving ADR001-ADR009.
- Extends text, JSON, SARIF, and future Action reporting for the new stable codes.

Repositories do not need to migrate existing ADRs. The v1.3 branch sets `VersionPrefix` to `1.3.0`; CI and release-policy tests derive versions from this value. The PR targets `main` and must pass CI before merging. Publication of `v1.3.0` is a separate, explicit manual release after integration.
