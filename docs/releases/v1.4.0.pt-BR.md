# Preparação da release v1.4.0

Este documento descreve o código-fonte preparado para revisão e a versão-base explícita de pacote **1.4.0**. Não representa publicação nem autorização para publicar.

- Validação Git incremental opcional e segura, preservando verificações globais de integridade.
- Baselines versionados e estritos, com geração/atualização atômica explícita e relatório new/existing/resolved.
- Cálculo de resoluções sobre a validação completa, aplicando o filtro de arquivos alterados somente a novos/existentes selecionados.
- Validação de referências Git e remoção de fingerprints duplicados no baseline.
- Revisão por IA comparando explicitamente duas versões do mesmo arquivo, sem enviar histórico/contexto implicitamente.
- Testes determinísticos de Git real, provider simulado, segurança, cancelamento e regressão.
- Documentação em inglês e português para histórico shallow, baseline, migração, comparação e CI segura em forks.

A branch v1.4 incorpora as correções de governança da v1.3 e as proteções de release/CI da v1.2. **Faça merge do PR #106 na main antes de redirecionar ou integrar o PR #107.** Execute novamente a CI sobre o commit integrado na main. Publique v1.3.0 e, depois, v1.4.0 apenas por execuções manuais e independentes do workflow, após os respectivos merges. A política de SemVer rejeita versões inferiores à versão-base do projeto e protege tags já publicadas.
