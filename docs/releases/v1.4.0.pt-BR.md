# Histórico do planejamento v1.4.0 (substituído)

**Estas notas descrevem a antiga branch de desenvolvimento, não uma release separada prevista para publicação.** As funcionalidades antes planejadas para v1.4 foram publicadas na versão consolidada **v1.3.0**. Consulte as [notas da v1.3.0](v1.3.0.pt-BR.md).

O escopo original da branch v1.4 incluía:

- Validação incremental opcional com Git, preservando verificações globais de integridade.
- Baselines estritos e versionados, com criação/atualização atômica explícita e relatório new/existing/resolved.
- Cálculo de resoluções sobre todas as ADRs antes do filtro de arquivos alterados.
- Validação de referências-base do Git e eliminação de fingerprints duplicados.
- Revisão comparativa por IA entre duas versões do mesmo ADR com contexto limitado.
- Testes determinísticos com Git real, provider simulado, segurança, cancelamento e regressão.
- Documentação bilíngue sobre histórico shallow, baselines, migrações, revisão comparativa e CI segura em forks.

Todo esse escopo foi publicado na **v1.3.0**, junto com MADR 4.0 e a governança de relacionamentos. As próximas publicações permanecem manuais e sujeitas à CI e à proteção de tags imutáveis.
