# Notas de preparação da v1.4.0

Este documento descreve código pronto para revisão, não uma release publicada.

- Adiciona validação incremental Git segura e opt-in, mantendo verificações globais obrigatórias de grafo/unicidade.
- Adiciona baseline JSON estrito, geração/atualização atômica explícita e relatório new/existing/resolved.
- Adiciona comparação Git explícita do mesmo arquivo ao review consultivo por IA, sem transmissão implícita de histórico/contexto.
- Adiciona testes determinísticos de Git/provider mock/segurança/falhas e orientação bilíngue segura para forks.

O PR v1.4 é encadeado na v1.3. Faça merge da v1.2 primeiro, retarget/merge da v1.3 depois e, por fim, atualize/retarget/merge da v1.4 em `main`. Execute o workflow manual existente de forma independente para v1.2.0, v1.3.0 e v1.4.0 somente após cada integração; estas notas não significam publicação.
