# ADR Guard v1.7.0

ADR Guard 1.7.0 adds versioned form contracts for trusted visual ADR creation and editing adapters. These notes describe the v1.7.0 release contents; public artifact availability must be confirmed separately on NuGet.org and GitHub Releases.

## Highlights

- `adr-guard new <directory> --form` supports native-template discovery, side-effect-free previews, and atomic creation through schema `1.0` stdin/stdout messages.
- `adr-guard edit <file> --form` supports format-aware loading and atomic in-place updates with external-change detection.
- Editing preserves existing filenames, ADR identifiers, unknown Markdown sections, and content outside the fields changed by the user.
- Existing command-line creation and validation behavior remains backward compatible.

## Install v1.7.0

After the coordinated release is published:

```shell
dotnet tool install --global RodriOliveira.AdrGuard --version 1.7.0
```

For an existing installation:

```shell
dotnet tool update --global RodriOliveira.AdrGuard --version 1.7.0
```

The VS Code extension remains an adapter over these contracts. Validation and ADR domain rules continue to be owned by the CLI.
