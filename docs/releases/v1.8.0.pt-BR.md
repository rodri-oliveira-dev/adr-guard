# Candidata a release do ADR Guard v1.8.0

[English](v1.8.0.md)

A CLI ADR Guard 1.8.0 está preparada como a release compatível com as candidatas, versionadas de forma independente, VS Code 1.1.0 e MCP 1.0.0. Estas notas descrevem artefatos preparados; elas não significam que pacotes NuGet, contêineres, tags da Action ou uma GitHub Release foram publicados.

## Incluído

- Preserva todos os comandos e contratos existentes da CLI: `init`, `check`, `baseline`, `index`, `new`, `edit`, `draft`, `review`, `impact` e `drift`.
- Preserva defaults de validação canônica, MADR 4.0 opcional, políticas de lifecycle/relacionamentos, baselines de diagnóstico, validação incremental, relatórios texto/JSON/SARIF, catálogos enriquecidos, análise de impacto, verificação de drift e fluxos de IA revisados por pessoas.
- Expõe os serviços de domínio existentes ao adaptador MCP somente leitura empacotado separadamente, sem mover políticas nem validação para fora do assembly da CLI.
- Fecha a entrada padrão de subprocessos Git para impedir que um processo filho consuma a entrada do protocolo MCP durante análises de impacto ou drift.
- Adiciona documentação bilíngue auditada e orientação de compatibilidade para CLI 1.8.0, VS Code 1.1.0 e MCP 1.0.0.

Nenhum comando, flag, schema de relatório, default ou significado de exit code da CLI é alterado intencionalmente nesta release. Draft/review por IA e resultados MCP continuam consultivos; pessoas controlam status e aprovação das ADRs.

## Instalação após a publicação

```shell
dotnet tool install --global RodriOliveira.AdrGuard --version 1.8.0
adr-guard --version
```

Para uma instalação global existente, use `dotnet tool update --global RodriOliveira.AdrGuard --version 1.8.0` somente depois que o NuGet.org listar essa versão exata. O workflow coordenado de release continua manual e restrito à `main`.

## Compatibilidade

- Runtime: .NET 10.
- A extensão VS Code 1.1.0 exige uma CLI compatível instalada separadamente; a CLI 1.8.0 é a versão recomendada para todos os fluxos visuais de arquitetura, governança e IA. Os contratos de criação/edição visual permanecem no schema `1.0` e compatíveis com CLI 1.7.0 ou superior.
- O MCP 1.0.0 é instalado de forma independente e não exige a extensão. A CLI não exige MCP nem VS Code.

Consulte a [matriz de compatibilidade](../compatibility.pt-BR.md), a [referência da CLI](../cli-reference.pt-BR.md) e o [processo de release](../github-action-release.pt-BR.md).
