# Complete ADR examples

[Português (Brasil)](README.pt-BR.md) · [Documentation home](../index.md) · [Template selection](../decision-design/choosing-a-template.md)

These examples express the same decision—using PostgreSQL as the order system of record—at three levels of structure. They contain completed reasoning rather than template prompts. Each language and format lives in a separate directory because every sample intentionally uses ADR ID `0001` and format selection applies to the whole validated set.

| Example | Why this form fits |
| --- | --- |
| [Minimal, English](canonical-minimal/en/0001-use-postgresql-for-order-data.md) · [Portuguese](canonical-minimal/pt-BR/0001-usar-postgresql-para-pedidos.md) | The decision can be understood from context, decision, and balanced consequences. |
| [Extended, English](canonical-extended/en/0001-use-postgresql-for-order-data.md) · [Portuguese](canonical-extended/pt-BR/0001-usar-postgresql-para-pedidos.md) | Reviewers need explicit drivers, alternatives, rationale, risks, and ownership. |
| [MADR 4.0, English](madr-4/en/0001-use-postgresql-for-order-data.md) · [Portuguese](madr-4/pt-BR/0001-usar-postgresql-para-pedidos.md) | The team uses MADR's option and decision-outcome structure. This is authored separately, not generated by `new`. |

The Portuguese examples keep invariant English structural headings so the matching validator can parse them. Their ADR filenames cannot use the normal `.pt-BR.md` documentation suffix because valid ADR filenames must match `NNNN-lowercase-kebab-case.md`; separate `pt-BR` directories provide localization without weakening that contract.

## Validate the samples

Build once, then run each isolated set with its declared mode:

```bash
dotnet build AdrGuard.slnx
dotnet run --project src/AdrGuard -- check docs/examples/canonical-minimal/en
dotnet run --project src/AdrGuard -- check docs/examples/canonical-minimal/pt-BR
dotnet run --project src/AdrGuard -- check docs/examples/canonical-extended/en
dotnet run --project src/AdrGuard -- check docs/examples/canonical-extended/pt-BR
dotnet run --project src/AdrGuard -- check docs/examples/madr-4/en --adr-format madr-4
dotnet run --project src/AdrGuard -- check docs/examples/madr-4/pt-BR --adr-format madr-4
```

Passing these checks confirms structure, filename, status, and references—not the technical merit or organizational approval of the example decision.
