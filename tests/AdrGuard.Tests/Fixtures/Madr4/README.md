# MADR 4.0 conformance fixtures

These fixtures use the structure of the official `adr/madr` tag `4.0.0` templates:

- <https://github.com/adr/madr/tree/4.0.0/template>
- upstream license: MIT OR CC0-1.0

Placeholder guidance was replaced with concrete test content. `minimal.md` covers the mandatory headings from `adr-template-minimal.md`; `full.md` covers optional front matter and optional full-template headings. They are conformance data, not ADR Guard documentation claims.
